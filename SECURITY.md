# Security and privacy

UptimeKite reads public HTTPS status APIs and stores configuration locally. It does not require credentials or administrator rights.

Do not include credentials, private URLs or personal data in public bug reports. To report a sensitive vulnerability, use the private vulnerability reporting option on this GitHub repository if enabled; otherwise contact the maintainer privately through an available GitHub profile contact channel.

The application validates endpoint schemes, bounds response sizes, limits concurrency, and preserves confirmed states on transport and parsing failures. Windows notifications and launch-at-sign-in integration are per-user.

Only download binaries from this repository's releases or build from source. Release checksums help detect accidental file changes; they do not replace code signing. No code-signing identity is currently configured.
